# Quick tip when using /to-tickets:

> Saved from X on 2026-08-11. Author: Matt Pocock.

Quick tip when using /to-tickets:

1. Think about how big the task is
2. Approximate how many tokens you'd need to spend to complete it (this takes experience - higher estimates are safer)
3. Divide that total by 150k (the approx smart zone of SOTA agents)
4. That gives you the number of tickets you need.

A big refactor might be 1M tokens. That's 6.66 smart zones, so 7 tickets.

Nice heuristic if you're not sure.
