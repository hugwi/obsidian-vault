# The Creator of Claude Code Doesn’t Prompt Anymore. He Writes AI Loops

![The Creator of Claude Code Doesn’t Prompt Anymore. He Writes AI Loops](https://www.youtube.com/embed/4YBldYC6Bw8)

## Description

The creator of Claude Code says he doesn’t prompt Claude anymore.

He writes loops.

And once you understand this, it completely changes how you use ChatGPT and Claude.

Most people ask AI once, get a draft, then manually keep saying:

“Make it shorter.”

“Try again.”

“Add a better hook.”

But with a loop, you tell AI the goal, how to judge the result, and when to stop.

Then it drafts, scores, critiques, rewrites, and only shows you the best versions.
