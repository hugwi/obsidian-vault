# Every Tech Bubble Obeyed the Same Rule. AI Is Next.

![Every Tech Bubble Obeyed the Same Rule. AI Is Next.](https://www.youtube.com/embed/KJxfSIvv920)

## Description

Some people think the AI bubble will crash like the dot-com bubble. Others think it will never pop at all. But what if they’re both missing something? History is full of technology bubbles that ended in completely different ways. Some technologies disappeared almost overnight. Others crashed spectacularly before quietly transforming the world decades later. But they all follow a surprisingly simple rule. And once you see it, you’ll never look at AI, or any future bubble, the same way again.
