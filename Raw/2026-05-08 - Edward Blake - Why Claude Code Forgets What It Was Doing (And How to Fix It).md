# Why Claude Code Forgets What It Was Doing (And How to Fix It)

![Why Claude Code Forgets What It Was Doing (And How to Fix It)](https://www.youtube.com/embed/Nnf-iOXwsxc)

## Description

Every Claude Code session has a finite context window. When it fills up, compaction happens and the session forgets what it was doing. In this episode I build two reusable templates — task_state.md and session_handoff.md — explain what survives compaction and what doesn't, and cover the CLAUDE.md token discipline that keeps your context budget from being consumed by your own configuration.
