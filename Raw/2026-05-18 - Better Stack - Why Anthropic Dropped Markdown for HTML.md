# Why Anthropic Dropped Markdown for HTML

## Transcript

Everyone thinks markdown is best for AI, but the Claude code team have pretty much stopped using markdown in favor of HTML. Farek from Anthropic says markdown breaks down once your agent starts doing serious work. If it writes a spec that's more than 100 lines, it becomes a wall of text that nobody wants to read. But HTML changes the game entirely. Claude can build diagrams with SVGs instead of creating ASCII art, builds actual tables with styling instead of markdown grids, and interactive prototypes with sliders and knobs where you can tweak the design in real time. Farek says he now creates HTML mockups for different plan options, and even attaches a HTML explainer to every PR he makes instead of relying on the GitHub diff. There are some real downsides. HTML takes two or four times longer to generate than markdown. The good diffs are noisy and basically useless for code review. And yes, it uses way more tokens. But Farek makes a point that people actually read the HTML output, but don't read the markdown ones. It also makes him feel like he's in the loop instead of blindly accepting every spec that Claude produces. If this convinced you to use HTML instead of markdown, let me know in the comments, and subscribe for more AI coding tips.
