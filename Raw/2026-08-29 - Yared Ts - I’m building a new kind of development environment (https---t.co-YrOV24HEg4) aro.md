# I’m building a new kind of development environment (https://t.co/YrOV24HEg4) around a problem I think AI coding is creating: cognitive debt.

> Saved from X on 2026-08-29. Author: Yared Ts.

I’m building a new kind of development environment (https://t.co/YrOV24HEg4) around a problem I think AI coding is creating: cognitive debt.

The basic idea is to stop treating the codebase as just a collection of files and turn it into a graph. Functions, classes, files, imports, and dependencies become connected, so you can see how different parts of the code relate to each other.

You can also attach documentation, tasks, logs, notes, and other context directly to the function or class they belong to. So instead of having this information spread across different files and tools, it stays connected to the code it describes.

The task manager uses the same graph. When you create a task, it can show which functions and parts of the code the task will affect or depend on. If two tasks are likely to change the same part of the code, you can see that before they conflict.

I’m building this because with AI coding agents, you can have several agents changing a codebase at the same time. It becomes difficult to know what each agent is working on, what parts of the code they are touching, and how their changes are connected.
