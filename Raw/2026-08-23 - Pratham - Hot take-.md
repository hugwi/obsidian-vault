# Hot take:

> Saved from X on 2026-08-23. Author: Pratham.

Hot take:

We don't need GitHub anymore. Or at least we need a new version of it, designed agent-first.

GitHub made sense when humans wrote code by hand. Developers needed a place to store code, iterate on it, and keep it backward compatible so if something broke, you could go back to a previous log and fix it. The whole workflow, PRs, issues, review, was built around a human being the one writing and reading every change.

Coding has changed now.

Agents write code and iterate at lightning speed. Why would an agent waste time reviewing its own code the way a human reviews a PR, when it can just reiterate and fix things in the same breath? The bottleneck GitHub was designed to manage doesn't really exist anymore.

We are early, so most agent workflows just bolt onto GitHub because it's what's there, not because it's the right interface. The real shift is from reviewing diffs to grading outcomes. Whatever wins here won't be GitHub with an AI button, it'll be built agent-first from scratch.
