# 7 Tools to reverse engineer any binary #shorts

![7 Tools to reverse engineer any binary #shorts](https://www.youtube.com/embed/Ib2SxsFZhOA)

## Description

7 reverse engineering tools that turn a compiled binary back into something you can read, trace, and understand.

These are the tools real reverse engineers use for malware analysis, CTFs, and figuring out how software actually works under the hood.

Tools in this video:

0:00 Ghidra - free NSA decompiler that turns machine code into readable C-style pseudocode
radare2 - scriptable command-line framework to analyze, disassemble, and patch
x64dbg - open-source debugger for stepping through Windows binaries
GDB - Linux debugging with a context dashboard for registers, disassembly, and breakpoints
Frida - dynamic instrumentation to hook functions and rewrite return values at runtime
Cheat Engine - memory scanner and live patcher for running processes
ImHex - modern hex editor with a pattern language and visual node graph

New to RE? Start with one tool that matches your target: a Windows app, a Linux binary, a mobile app, or a raw file.
