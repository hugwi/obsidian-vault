# A Japanese developer discovered a seriously underrated Claude Code trick.

> Saved from X on 2026-08-22. Author: divyansh tiwari.

A Japanese developer discovered a seriously underrated Claude Code trick.

Install the "Find Skills" skill, then simply ask:

“Is there a good skill for [YOUR GOAL]?”

Claude can discover the right skills for your project and use them to get the job done more effectively.

Install it:

npx skills add https://t.co/Xl56bAz6gL --skill find-skills

This is one of those tiny Claude Code tricks that can completely change how you build with it.

Save this. You’ll thank yourself later.
