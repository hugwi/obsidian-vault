Coding Agents: AI Driven Dev Conference | The Future of AI-Powered Software Development

AI coding agents are rapidly changing how developers write, debug, and ship software. In this AI-Driven Dev Conference session, experts share real-world lessons from building and deploying AI coding agents, developer copilots, and autonomous programming tools.

This discussion explores how modern AI developer tools interact with large codebases, how teams design agent workflows, and what it takes to build reliable systems where AI and developers collaborate to write production software.

Speakers dive into practical topics including context engineering, prompt design, agent orchestration, and debugging AI-generated code. You’ll also hear insights on managing large repositories, building toolchains for AI agents, and structuring systems that allow coding agents to operate safely in real development environments.

If you’re interested in AI-assisted coding, LLM developer tools, agent frameworks, or the future of AI-driven software engineering, this session provides practical insights from engineers actively building these systems.
