## Transcript

The animation is already finished, but the client suddenly wants a different version. What do you do? With hundreds of keyframes already in place, directly editing the original animation can easily mess up the existing motion. Blender's NLA editor allows you to layer new animation on top of your existing motion. First, push the original animation down into the NLA editor, then create a new action and set the blend mode to combine. Now, you only need to adjust the controllers you want to modify. The new animation will be combined with the original motion without changing your original animation. You can quickly create a new version.
