# Deepseek Harness: Not What You Think

![Deepseek Harness: Not What You Think](https://www.youtube.com/embed/y0BW4hpMpyM)

## Description

In this Video, I break down DeepSeek Harness and the engineering idea that could matter more than the model score itself: the harness is part of the benchmark. The same model can produce dramatically different results depending on the software environment, tools, context handling, and agent loop wrapped around it.

We explore why DeepSeek's reported 87.9 Terminal Bench score needs to be understood alongside its testing setup, and how identical model weights can produce significantly different results under different harnesses.

Then we get into the genuinely interesting engineering: DeepSeek's append-only event log and the rule that once information has been sent to the model, you don't modify what came before it. The architecture preserves byte-for-byte prompt stability, allowing prefix caching to remain effective across long agent sessions.

At the time described in the project's design notes, DeepSeek's cache-hit versus cache-miss pricing difference was roughly 120x, making cache stability a major engineering concern for long-context workloads. We also examine why moving summarization instructions from the beginning to the end of a request helps preserve the cached prefix.

The video also covers:

• Why the AI model is only half of an agentic benchmark
• How the harness can contribute several benchmark points without changing model weights
• DeepSeek's append-only session architecture
• Prefix caching and why changing earlier tokens can become extremely expensive
• The unusual trade-off between speed, token usage, cost, and output quality
• DeepSeek Harness integrations for Claude Code and Codex
• Plugin architecture, permissions, and security concerns
• Public design notes and agent-generated engineering records
• DeepSeek's published post-mortems and what they reveal about agent failures
• Changes to DeepSeek's cache pricing and discount structure
• Why an independently submitted DeepSeek Harness result on Terminal Bench would make the benchmark claim far more meaningful
