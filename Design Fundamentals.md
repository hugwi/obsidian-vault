# Design Fundamentals

> Hub: [[Design]] · the agent side: [[AI Design]] · taste library: [[Inspiration]]

The human-side judgment the tools are trying to encode. None of this depends on an
agent, a skill or an MCP — it is the craft that tells you whether the output is any
good. Read once, then reach for it when a review needs a reason rather than a vibe.

## Visual craft

- **[[7 Rules for Creating Gorgeous UI]]** — Erik Kennedy, and the best single entry
  point if you have no art background. Light comes from the sky, so shadows tell the
  brain what it is looking at. Design in black and white first, add colour last.
  Double your whitespace. Learn to pick and pair type rather than inventing it.
- **[[Every UIUX Concept Explained in Under 10 Minutes]]** — Kole Jain. Containers as
  affordance signifiers, hierarchy through size / position / colour, four-point spacing
  grids, one font family per design, and a response state on every interaction.
- **[[UX UI tips A guide to creating buttons]]** — Sarah Edwards. Button anatomy
  (corner radius, padding, safe space, shadow), the full state set
  (default / hover / pressed / focused / disabled), minimum 10mm × 10mm tap targets,
  WCAG contrast on the label.
- **[[142 JavaScript Text Effects]]** — implementation reference for type treatment
  once a direction is chosen.

## Design as a discipline

- **[[Beck Design Rules]]** — simple design applied to code rather than pixels, but the
  underlying discipline is identical: minimal elements, clear intent, nothing that does
  not earn its place.
