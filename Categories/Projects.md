# Projects

```dataviewjs
await dv.view("Templates/Scripts/project-desk", {mode: "board"});
```

> Each project note carries `status:` — `active` · `pursue` · `paused` · `done` — and
> ideally an `outcome:` (one sentence, past tense) and a `due:`. Anything with a
> `project:` property or a wikilink to the project note is gathered onto that
> project's desk, whatever folder it lives in. See [[Project workflow]].
